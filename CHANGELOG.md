# Changelog

## 0.2.0

- Uniform charcoal `#151515` across editor, sidebar, panels and terminal (no more OLED true-black crush)
- Reds replaced with lavender for keywords; errors moved to burnt orange
- HTML intrinsic tags split from components: blue tags, gold components
- Functions and methods moved to sage; user types to teal, primitives to gray; gold now exclusive to components
- JSON and `.env` keys in blue, values muted
- Full markdown styling: gold headings and bullets, blue links, italic quotes
- Comments and widget backgrounds lifted for the lighter base

## 0.1.0

- Initial release: OLED near-black surfaces with inverted depth (content darker than chrome)
- Earthy palette: brick keywords, gold components/types, sage strings, teal constants, dusty blue functions
- Injection grammar: PascalCase vs camelCase function split, `as`-as-value fix
- Colored terminal ANSI, diagnostics, git decorations and diffs
- JSON and `.env` key/value treatment
